⑤ 미탐 사례 엔진 #245(RF 분류, 위험 확률 0.36 이상, validation). 남은 수명 40~21 위험 구간 19사이클 동안 경보가 거의 없었음. 위험 진입 때 s3 온도가 다른 엔진 평균(517°C)보다 낮아 낮은 온도에서 고장 나는 개체. 고장 약 20사이클 전에는 경보가 울려 완전 누락은 아니지만 정비 준비 기간(7~32사이클)에는 늦을 수 있음. 변화량 특성 실험(scripts/17_engine_baseline_features.py): 각 엔진의 처음 30사이클 평균을 그 엔진의 초기 상태로 삼아 현재값과 최근 15사이클 평균의 변화량을 특성으로 추가(RF는 특성 60 → 90개, GRU는 센서 15개 + 변화량 15개 입력 등 3가지 변형). 엔진 분할·학습 설정·경보 기준(RF 0.36, GRU 예측 40 이하)은 그대로, 시드 42 한 번. RF: 이 엔진(#245) 놓침 19 → 5사이클, 전체 validation 놓침 227 → 182, 헛경보 337 → 378, F1 0.863 → 0.867(거의 같음), test 놓침/헛경보 4/8 → 3/7. #179 헛경보는 59 → 72로 오히려 늘어남. GRU(변화량만 입력): #245 놓침 6 → 0, 그러나 헛경보 엔진 10 → 29대, validation F1 0.915 → 0.879, 검증 MAE 7.8 → 11.0, test MAE 17.3 → 19.0, test 놓침/헛경보 8/1 → 2/4. GRU(센서 + 변화량): 놓침 382사이클로 늘고 test 재현율 하락. 결론: 엔진 개체 차이를 반영하면 해당 엔진의 놓침은 줄지만 다른 엔진에서 헛경보가 늘어 전체 성능은 나아지지 않음. 한계: 시드 1회, 초기 30사이클 하나의 설정만 시험, 경보 기준 재조정 안 함. #179 오탐은 변화량 특성으로도 해결되지 않음(RF 59 → 72, GRU 41 → 39).
